- [CBS SAP AI](https://clockwork.in/clockworkai-sap-business-one-ai-solution/) **`C`** - Queries SAP Business One data on customers, orders, invoices, inventory and stock, and creates or updates sales orders, quotations, purchase orders, deliveries, goods receipts, invoices and payments. *Use case: Checking stock of an item across 3 warehouses, creating a sales order for a repeat customer, recording a supplier payment for last month's invoice.*
- [fairyfly](https://fairyfly.io) **`C`** - Operates the user's open SAP GUI for Windows session, starting transactions, reading screens, tables and messages as structured data, opening value help, and filling and submitting forms with approval at the PC. *Use case: Starting a transaction to look up open purchase orders for a vendor, filling in a goods receipt form and approving the change at the PC.*
- [mcpbizapps](https://mcpbizapps.com) **`C`** - Looks up SAP Business ByDesign customers, suppliers, sales orders and delivery status, receivables and payables aging, stock and project budgets, and prepares sales order changes that run after approval with an audit log. *Use case: Checking open receivables for a key customer over 60 days, changing the quantity on a sales order and sending it for approval.*
- [SAP CAP MCP Server](https://cap.cloud.sap) - Searches CDS models and CAP documentation for AI-assisted development of SAP Cloud Application Programming Model (CAP) projects. *Use case: Finding an entity definition in a project's CDS models, looking up CAP documentation while developing a CAP project.*
- [SAP Fiori MCP Server](https://www.sap.com/products/technology-platform/fiori.html) - Generates SAP Fiori elements apps from OData services or CAP in List Report, Object Page and Flexible Column layouts, lists Fiori apps and SAP systems, downloads OData service metadata, searches docs and runs functionality to adapt existing apps. *Use case: Generating a List Report and Object Page app from an OData service, adapting an existing Fiori elements app.*
- [SAP MDK MCP Server](https://developers.sap.com/topics/mobile-development-kit.html) - Creates, generates, validates, migrates and deploys cross-platform SAP Mobile Development Kit (MDK) applications and looks up MDK documentation. *Use case: Creating a new MDK app, validating and migrating an existing one, deploying a cross-platform mobile app.*
- [SAPUI5 MCP Server](https://sapui5.hana.ondemand.com) - Creates SAPUI5 and OpenUI5 apps and integration cards, runs the UI5 linter and manifest validation, and reads API reference, project and version info, and development, integration card and TypeScript conversion guidelines. *Use case: Scaffolding a new UI5 app, linting a project and validating its manifest, following the guidelines to convert an app to TypeScript.*
